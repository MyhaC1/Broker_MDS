### Соседние утверждения в `CLAUDE.md` — проверены, вывод пришлось сузить

Проверялись заодно, потому что стояли в том же абзаце и подавались так же.
Первая редакция этого документа заключала, что они не подтверждаются. **Это было
на шаг дальше, чем позволяли данные**, и штаб поправил (`_brain/РЕШЕНИЯ.md`,
Р-008). Разница существенная, поэтому она здесь, а не вычеркнута.

- «**38 закрытых багов, каждый с записанным уроком**» и «**отдельный раздел
  `docs/reference/Эксплуатация.md`**» — **существовали.** Не в репозитории, а на
  тестовом VPS, в `/opt/site-web/Broker_MDS/docs/`: 10 ADR, 38 багов, 22 задачи,
  справочники, журнал выкаток. Код на сервер заливали **архивами**, `.git` там
  нет — поэтому в истории git этих файлов и не могло быть. Доступ к машине
  потерян, вейлт вместе с ним (`_brain/ВОССТАНОВИТЬ-ДОСТУП.md`, п. 2).
- Что доказал мой `git log --all --diff-filter=A -- 'docs/*'`: каталога `docs/`
  не было ни в одном коммите **этого репозитория**. Ровно это, и ничего сверх.
  «Нет в git» и «не существовало» — разные утверждения; я подставил второе
  вместо первого, потому что искал в единственном месте, которое мог видеть.
- «**Твой формат документации взят за образец для всей биржи**» — относилось к
  тому же вейлту. Образцом для журналов теперь служит

**Практическое следствие для MDS не изменилось:** журналы заводятся с нуля,
восстанавливать нечего. Изменилось другое — это документация **потерянная**, а не

## Как перепроверить

```bash
pnpm install
pnpm test                     # 9 тестов
pnpm typecheck                # чисто
pnpm dev                      # :3003, ждать «[binance] connected»
node scripts/smoke.mjs        # 6 проверок, ожидается ALL OK
```

Пересчёт истории (та же таблица):

```bash
for c in $(git log --format=%h --reverse); do
  echo "$c it=$(git show $c:src/catalog.test.ts | grep -c '  it(')" \
       "checks=$(git show $c:scripts/smoke.mjs | grep -c '^check(')"
done
```
