# Реестр провайдеров · контракт служебной ручки

Для задачи **CMS-13** (страница переключателя в админке). Решение и
обоснования — в `ADR-031`. Здесь только то, что нужно, чтобы написать клиента.

Направление связи одно: **админка → MDS**. MDS в CMS не ходит и ходить не
должен.

## Адрес и доступ

| | |
| --- | --- |
| База | `MDS_HTTP_URL` (контур: `http://localhost:3103`; локально `:3003`) |
| Заголовок | `X-MDS-Admin-Token: <MDS_ADMIN_TOKEN>` |
| CORS | заголовка нет сознательно, `OPTIONS` → 405. **Звать только с сервера** |

Секрет общий для обеих сторон, задаётся окружением. Требования: ASCII без
пробелов, не короче 24 символов. Нарушение — ручка выключается целиком.

| Ответ | Что значит | Что делать админке |
| --- | --- | --- |
| `503 control-plane-disabled` | секрет у MDS не задан или непригоден | показать «управление провайдерами выключено на стороне MDS», **не** «нет доступа» |
| `401 unauthorized`, `detail: no-token` | мы не послали заголовок | ошибка клиента |
| `401 unauthorized`, `detail: bad-token` | секреты разошлись | показать «секрет не совпал» |
| `503 registry-unreadable` | файл реестра на MDS битый | показать причину из `detail`, **править нечего, пока файл не починят** |

Эти четыре различаются намеренно: «выключено» и «не пустили» чинят разные
люди.

## `GET /v1/admin/providers`

```jsonc
{
  "registry": {
    "version": 3,
    "updatedAt": "2026-10-19T18:00:00.000Z",
    "updatedBy": "админка CMS",
    "providers": [
      {
        "id": "binance",
        "adapter": "binance",
        "label": "Binance — публичные данные, ключ не нужен",
        "enabled": true,
        "priority": 10,
        "covers": ["crypto"],
        "maxSilenceMs": 60000,
        "requiresKey": false
      }
    ],
    "categoryPrecedence": ["forex", "metals", "indices", "stocks", "energy", "crypto"]
  },
  "origin": "file",
  "adapters": ["binance", "twelvedata"],
  "routing": {
    "unit": "канонических символов каталога после разрешения коллизий",
    "checked": 525, "routed": 508,
    "byReason": { "primary": 508, "failover": 0, "silent": 0, "source-disabled": 17, "no-source": 0 },
    "byProvider": [{ "providerId": "binance", "symbols": 508 }],
    "hiddenByCollision": 1
  },
  "keys": [{ "providerId": "twelvedata", "required": true, "present": false }]
}
```

**`origin` показывать обязательно.** `builtin-default` означает **«никто не
настраивал»** — не то же самое, что «настроено так». В интерфейсе это должно
читаться как состояние по умолчанию, а не как выбор.

`adapters` — перечень того, для чего в MDS есть код. **Добавить источник с
адаптером не из этого списка нельзя**, и форма не должна этого предлагать:
новый протокол — это работа команды MDS, а не правка данных.

`keys[].present` — только факт наличия ключа. Сам ключ ручка не отдаёт
никогда и **не принимает**: ввод ключей через админку пока не реализован
(ADR-031, раздел о ключах), ключ задаётся окружением MDS.

## `PUT /v1/admin/providers`

Тело — объект реестра **целиком**, не дельта. Обязательно:

- `version` — та, что пришла в `GET`. Не совпала → `409 version-conflict`.
  Это защита от потерянного обновления: две вкладки админки иначе затирают
  правки друг друга молча. Правильная реакция клиента на 409 — перечитать и
  показать человеку, что состояние изменилось, а не повторить запись;
- `updatedBy` — кто правит. Попадает в журнал. Это **утверждение клиента**,
  а не проверенный факт: ручка знает только то, что у звонившего был секрет;
- `providers`, `categoryPrecedence`.

Поля `version`, `updatedAt`, `updatedBy` MDS выставляет сам; присланные
`version` сверяется, `updatedAt` игнорируется.

**Разбор строгий.** Незнакомое поле → `400 invalid-registry` с перечнем
проблем в `detail`. Это намеренно: молча отброшенное поле — это настройка,
которую администратор считает заданной, а она не задана.

Ответ `200`:

```jsonc
{
  "registry": { "version": 4, "...": "..." },
  "applied": {
    "changed": [{ "symbol": "XAUUSD", "from": "twelvedata", "to": "metals-alt" }],
    "invalidated": 494,
    "started": ["metals-alt"], "stopped": ["twelvedata"],
    "missingKeys": []
  },
  "persisted": true
}
```

**`invalidated` показывать человеку.** Это число цен, забытых в момент
переключения, — то есть сколько инструментов прямо сейчас остались без
котировки. Оператор должен видеть масштаб того, что он сделал.

Ответ `207` вместо `200` означает `persisted: false`: правка принята в память
и **не записана на диск**, то есть переживёт только до рестарта. Показывать
как предупреждение, а не как успех.

## Что меняется на стороне котировок при переключении

Читать перед тем, как рисовать кнопку.

1. Цены источников, переставших вести символ, **забываются немедленно** — не
   доживают до порога свежести. В `/v1/quotes` символ уходит в `unavailable`
   с причиной.
2. Каждая котировка несёт `source`. **Смена значения `source` на символе —
   это разрыв ряда цен, а не очередной тик.** Потребителю (терминал,
   витрина) положено закрыть на этой границе текущую свечу и перевзвести
   триггеры: другая площадка котирует по-своему, и стоп может сработать на
   движении, которого не было на рынке.
3. Переключение источника по инструменту, по которому **есть открытые
   позиции**, — операция с последствиями, и MDS о позициях не знает.
   Вопрос «запрещать ли такое из админки» открыт и адресован штабу.

Поэтому страница переключателя обязана предупреждать перед применением, а не
применять молча.

## Коды недоступности символа (`/v1/quotes` → `unavailable[]`)

Машинные, не переводятся; подпись для человека — отдельно.

| Код | Значит | Чинит |
| --- | --- | --- |
| `registry-unreadable` | реестр на MDS битый | команда MDS / оператор файла |
| `no-source` | ни один источник не ведёт символ | оператор: включить покрытие |
| `source-disabled` | источники есть, все выключены | оператор: включить |
| `source-silent` | источник назначен, цены нет | смотреть `/health` |
| `stale` | цена есть, старше порога | смотреть `/health` |
| `threshold-unset` | `QUOTE_STALE_AFTER_MS` не задан | окружение MDS |
| `not-in-catalog` | символа нет во вселенной | это не ошибка источника |

**Стиль кодов — kebab-case, решение штаба Р-087 (`_brain/КОНТРАКТЫ.md` §4г).**
До 20.10 эти же коды писались через подчёркивание (`not_in_catalog` и так
далее); переименованы до появления первого потребителя, читателей у старых
имён не было. Новое имя заводится **в §4г контрактов, а не в коде**.

Коды в таблице доступа выше (`control-plane-disabled`, `no-token`,
`bad-token`, `registry-unreadable`, `bad-body`, `version-required`,
`version-conflict`, `invalid-registry`, `method-not-allowed`, `not-found`)
переименованы тем же заходом. Это **третье** перечисление, не названное в
Р-087: ось символа и ось канала им описаны, а коды отказа служебной ручки —
нет. Они не ось канала: ось канала называет потребитель про себя
(«не настроено», «сеть»), а эти называет MDS про запрос к себе.

## Переменные окружения MDS

| Переменная | Умолчание | Что будет без неё |
| --- | --- | --- |
| `MDS_ADMIN_TOKEN` | **нет** | ручка выключена целиком (503) |
| `MDS_REGISTRY_PATH` | `./data/providers.json` | — |
| `MDS_PROVIDER_KEY_<ID>` | нет | источник с `requiresKey` не запускается, назван в `/health.registry.missingKeys` |
| `MDS_ROUTING_RECHECK_MS` | 5000 | — |
| `QUOTE_STALE_AFTER_MS` | **нет** | котировки не отдаются вовсе (§5г) |

Файл реестра обязан пережить рестарт: в контуре это том, иначе переключатель
работает до первого деплоя.
