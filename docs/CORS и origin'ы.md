# CORS и origin'ы: списка не существует

Задача MDS-04a — записать факт, обнаруженный попутно при MDS-01. Здесь только
то, что есть в коде; реализация проверки отложена (MDS-04b, см.
[[Технический долг]]).

## Где зашито

Два места, оба — жёсткая звёздочка, без переменной окружения и без условия:

- [`src/index.ts:64`](../src/index.ts#L64) — `res.setHeader('Access-Control-Allow-Origin', '*')`
  на **каждый** HTTP-ответ: `/health`, `/v1/instruments`, `/v1/quotes`,
  `/icons/*`, даже 404.
- [`src/hub.ts:20`](../src/hub.ts#L20) — `cors: { origin: '*', methods: ['GET', 'POST'] }`
  в конструкторе socket.io, то есть на WS-фан-аут котировок.

## Чего нет

`CORS_ORIGINS` **не существует** — ни в `src/config.ts`, ни в `.env.example`, ни
в `docker-compose.yml`, ни в `Dockerfile`. Проверено grep'ом по всему
репозиторию: строка встречается только в постановке задачи. Списка origin'ов,
который «ведётся здесь руками», нет — и никогда не было. Это не разъехавшийся и
не устаревший список, это пустое множество.

Следствие для приёмки: пункт «проверено вживую, что запрос с чужого origin
отклоняется» в текущем коде выполнить нельзя. Отклонять нечем.

## Что это значит сейчас — и чего это НЕ значит

**Ключи провайдеров через CORS не утекают.** Они живут в env сервиса, наружу
уходят только котировки. Граница ключей звёздочкой не затронута — это главное,
и оно в порядке.

**Квоты провайдеров чужие потребители не жгут.** Это стоит сказать отдельно,
потому что интуиция подсказывает обратное, а код говорит иначе — проверено по
коду, а не предположено:

- Twelve Data: `connect()` запускает поллер по **всей вселенной** провайдера на
  фиксированном интервале (`src/providers/twelvedata.ts`, `poll`/`schedule`);
  число подписчиков в расчёт не входит нигде. Кредиты тратятся одинаково при
  нуле потребителей и при тысяче.
- Binance: при коннекте идёт `SUBSCRIBE` на `@ticker` всех пар вселенной
  (`src/providers/binance.ts`), тоже независимо от подписчиков. Стримы
  публичные и бесплатные.

MDS мультиплексирует по построению: расход у провайдера **константный**. Чужой
потребитель не добавляет к нему ни одного запроса.

**Что открытый CORS стоит на самом деле** — две вещи, обе не про провайдера:

1. **Наши собственные ресурсы.** Каждый чужой клиент — это socket.io-соединение,
   состояние подписки в памяти хаба и трафик фан-аута. Ограничения на число
   клиентов в сервисе нет.
2. **Редистрибуция данных, за которые мы платим.** Любой сайт может встроить наш
   поток котировок к себе, и для платных категорий Twelve Data это ровно риск
   R-T5 из README — редистрибуция, условия которой прописаны в ToS провайдера.
   Пока ключа Twelve Data нет, отдаются только публичные данные Binance, и цена
   вопроса нулевая. Она перестанет быть нулевой в тот день, когда появится
   платный ключ.

Локально всё это стоит ноль: сервис слушает `localhost`. Цена появляется в тот
момент, когда MDS оказывается на машине, доступной снаружи, — поэтому именно это
событие записано триггером в [[Технический долг]].
