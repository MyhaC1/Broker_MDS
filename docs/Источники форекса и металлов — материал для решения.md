# Форекс, металлы, индексы: кандидаты на бесплатный источник

**Это не рекомендация и не выбор команды.** Выбор источника за владельцем
(Р-047). Здесь собрано то, что можно проверить по страницам провайдеров, —
чтобы решение принималось по данным, а не по памяти.

Собрано 19.10.2026. **Числа без ссылки не приводятся; непроверенное помечено
«не проверено» и это не придирка:** правдоподобное неверное число здесь
дороже дырки, потому что по нему выберут провайдера.

Крипта закрыта Binance (публичный поток, ключ не нужен) и в сравнение не
входит.

## Главный вывод, который меняет постановку вопроса

**Ограничивают не лимиты, а право показа.** Четыре провайдера, технически
подходящие, прямым текстом запрещают показывать данные нашим пользователям
на бесплатном тарифе:

| Провайдер | Формулировка |
| --- | --- |
| Twelve Data | внешний показ только через платный Redistribution Rights Add-On (ToS §2.2(e), §2.4) |
| Tiingo | «Internal Use Only… only for your own personal use» |
| Finnhub | «strictly for personal use»; «Personal plan can't be used by any business even internally without a written approval» |
| Alpha Vantage | «for personal, non-commercial use, unless… agreed otherwise in writing» |

Все бесплатные тарифы семейства APILayer (exchangerate.host, currencylayer,
marketstack) помечены «Non-Commercial Use» прямо на странице тарифов.

Практический смысл: **«бесплатно» у большинства означает «бесплатно для себя,
не для показа клиентам»**. Для брокерской витрины это не нулевая цена, а
юридический риск, и он не снимается аккуратной архитектурой.

## Второй вывод: половина «бесплатных» источников обновляется раз в сутки

Frankfurter / ЕЦБ, ExchangeRate-API, Fixer, exchangerate.host, marketstack —
референсные курсы, не котировки. ЕЦБ сам пишет: публикуется раз в рабочий
день около 16:00 CET, «published for information purposes only», и дословно
**«Using the rates for transaction purposes is strongly discouraged»**.

Для торгового терминала это мёртвые варианты при любых лимитах. Frankfurter
при этом единственный с чистой лицензией (open source, коммерческое
использование разрешено) и годится как источник **исторических дневных
курсов** или для пересчёта валюты интерфейса — но не как котировки.

## Три, на которые стоит посмотреть, и почему

**1. Публичный BBO-фид Swissquote — единственный по-настоящему бесплатный
real-time источник, закрывающий и форекс, и металлы.** Проверен живым
запросом: EUR/USD, USD/JPY, XAU/USD, XAG/USD с bid/ask и миллисекундным
таймстемпом, который рос между вызовами, — то есть это не кэш. Ключ не нужен.

Риск ровно один и он большой: **юридических условий на фид найти не удалось
вообще**. Это витрина брокера, а не API с лицензией. Фид может быть закрыт
или заролимичен без предупреждения, и нет никаких оснований считать, что
Swissquote согласен на показ своих котировок в чужом терминале. Закладывать
в продакшн без письменного ответа от них нельзя.

**2. TraderMade — самый близкий коммерческий вариант.** Единственный, кто в
одном API даёт форекс + драгметаллы + индексные CFD через WebSocket.
Бесплатного тарифа на странице цен сегодня нет.

**3. Twelve Data — лучший технический фит, но платный по факту.** Один API на
всё, внятная модель кредитов, адаптер у нас уже написан и работает. Но
металлов на Basic нет, а внешний показ требует отдельного add-on. Разумнее
запросить цену «commodities + Redistribution Rights», чем пытаться вписаться
в бесплатный тариф.

Finnhub стоит отбросить несмотря на привлекательный бесплатный WebSocket:
«не может использоваться бизнесом даже внутренне без письменного согласия»
не оставляет места для толкования.

## Индексы — отдельная юридическая история

Ни один из проверенных источников не даёт индексы бесплатно с правом показа.
Данные по индексам лицензирует правообладатель индекса (S&P, биржи), и показ
требует соглашения **с ним**, а не только с API-провайдером. По конкретным
договорам это не проверялось. Вывод для планирования: индексы в бесплатный
контур закладывать не стоит — это самая вероятная юридическая ловушка.

## Что обязан подтвердить человек, прежде чем это станет решением

1. **Swissquote** — письменный ответ, допустимо ли использование публичного
   BBO-фида в стороннем продукте, есть ли лимиты. Без ответа — не закладывать.
2. **TraderMade** — размер бесплатного тарифа сегодня, входит ли в него WS,
   пункт о redistribution в их соглашении.
3. **Twelve Data** — цена add-on и с какого тарифа открываются металлы; плюс
   §2.3(g) о допустимых сроках кэширования — конкретные сроки в ToS не
   названы, их надо найти в документации.
4. **Finnhub** — лимиты 60/мин и 50 WS-символов прочитать глазами в браузере
   (страница рендерится скриптом, автоматически не читается).
5. **Massive (бывший Polygon)** — есть ли вообще бесплатный тариф по валютам
   после ребрендинга.

## Что из этого следует для кода

**Ничего срочного, и это главное.** Добавление любого из кандидатов — правка
реестра плюс адаптер, если протокол новый. Swissquote и TraderMade потребуют
нового адаптера (их форма ответа своя); Twelve Data уже написан.

Напоминание из `ЗАДАЧИ.md`: **появление платного ключа включает отложенную
MDS-04b** — проверку origin. Это про условия договора о редистрибуции, а не
про периметр: пока наружу идут публичные данные Binance, цена нулевая.
